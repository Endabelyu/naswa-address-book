# **Contact Address Book**

---

## Overview

This project is a part of the Bearmentor Bootcamp (Batch #4) and serves as a learning exercise to enhance my web development skills. This application allows users to create, edit, and delete contact information.

## Features

- **Add Contacts:** Users can add new contact information.
- **Edit Contacts:** Users can modify existing contact details.
- **Delete Contacts:** Users can remove contacts from the address book.
<!-- - **Responsive Design:** Built with Tailwind CSS to ensure the application is mobile-friendly. -->

## Technologies Used

- **HTML:** Markup language for structuring the web page.
- **Tailwind CSS:** A utility-first CSS framework for styling.
- **Vanilla JavaScript:** For implementing the application's functionality.
